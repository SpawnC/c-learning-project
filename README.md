C Learning Project

This repository documents my journey of learning the C programming language through practice, experiments, and small projects.

Most of the code in this repository was written by me while studying C independently. The examples cover fundamental language features, memory management, pointers, arrays, strings, structures, file I/O, and other topics.

Repository Structure

The repository contains my original learning exercises and experiments, organized by topic.

- "variables/" — variables, types, constants, and scope
- "conditions/" — conditional statements and logical operators
- "for/" and "while/" — loops and iteration
- "arrays/" and "strings/" — arrays, strings, and basic operations
- "pointers/" — pointers and memory addresses
- "dynamic_memory/" — dynamic memory allocation and deallocation
- "structs/" — structures and type definitions
- "file_io/" — reading and writing files
- "bit_operations/" — bitwise operations
- "function/" — functions and recursion
- "mini_projects/" — small practical projects

AI-Assisted Contribution

The "advanced_memory/" directory is the only directory in this repository created with the assistance of AI.

This directory was generated by ChatGPT as a separate educational example exploring arena-based memory allocation in C. It contains three files:

- "arena.h" — the arena allocator interface and data structure
- "arena.c" — the allocator implementation, including alignment and bounds checks
- "demo.c" — a small demonstration of allocating objects, resetting the arena, and releasing its memory

The purpose of this directory is to explore a more advanced memory-management technique and provide an opportunity to study and understand the implementation.

All other directories and learning exercises represent my own independent work. The AI-assisted directory is explicitly separated so that its contribution is transparent.

Purpose

This repository is a personal learning project, not a claim of expertise or a production-ready C library. It reflects my progress as I study the language, practice writing code, and explore increasingly advanced concepts.

The code may evolve as I revisit earlier topics and improve my understanding.
